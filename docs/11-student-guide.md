# Student Guide

Everything a student can do on L.O.O.M., in the order it unlocks.

## 1. Getting in

1. Open the app and choose **Get started** (register) or **Sign in**. There is a single login for everyone.
2. On first visit a profile is created for you automatically and attached to your chapter.
3. Your chapter admin can promote helpers to `admin` later — there is nothing to configure yourself.

## 2. Your first week (the Start-here checklist)

The dashboard shows five steps until they are all done:

| # | Step | Where |
|---|------|-------|
| 1 | Set your direction (pick a track) | Onboarding |
| 2 | Complete your first roadmap node | Learn → Roadmap |
| 3 | Learn from a curated resource | Learn → Resources |
| 4 | Ship your first project | Build → Projects → New project |
| 5 | Connect GitHub | Build → GitHub |

## 3. Navigation groups

The top bar has six tabs; each opens a menu except Home and Proof.

- **Home** — welcome card, skill radar (you vs chapter average per track), Start-here checklist.
- **Learn** — Roadmap (interactive graph: click a node for the detail drawer, mark complete, open linked resources, move prev/next), Resources (5 tracks: AI/ML, Web, Cybersecurity, DSA, Blockchain; search + level + kind filters; mark resources complete), Insights (consistency, roadmap %, 14-snapshot activity bars, anonymous peer comparison, chapter rank, one recommended next step).
- **Build** — Projects (create with repo URL + `#tags`, filter by tag), GitHub (link username so webhooks attribute commits to you; 14-day activity; **Export JSON** downloads your stats), Open Source (browse curated repos with live stars + good-first-issue counts; claim a PR/issue URL; merges auto-verify via webhook and award badges into your badge journal).
- **Compete** — Contests (register, submit), Events (register, get a door code, give feedback after attending, collect certificates), Standings (chapter progress board: your rank, score breakdown, College/Everywhere/Circle scopes).
- **People** — Mentors (request sessions, review mentors), Community (forums with voting + marked solutions, wiki with suggested edits, code snippets), Network (chapter profiles, partnerships, federation stats), Discover (trending threads, rising builders, top mentors; claim your `@username` here if you have none).
- **Proof** — achievements ledger, portable skill card, and **Create share link** per achievement (signed URL any recruiter can open). Certificates from events live under Events detail pages.

Secondary icons (top bar): Alerts (notifications), Privacy (your data controls), Settings.

## 4. How proof is earned

| Proof | How |
|-------|-----|
| Roadmap % | Mark nodes complete (evidence-linked where required) |
| OSS badges | First PR → Triple Merge → OSS Regular → Code Reviewer (auto on merge) |
| Achievements | OSS badges mirror automatically; admins can issue manual/contest badges |
| Share links | You issue per achievement; valid up to 2 years, view-counted |
| Certificates | Attend an event; admin checks you in at the door; printable page issued |
| Reputation | Computed live: achievements ×10, verified OSS ×20, forum solutions ×15, wiki pages ×10, events ×5, endorsements ×2 — shown on your `@username` card |

## 5. Public identity

- Claim a username (2–30 chars, letters/numbers/`-`/`_`) to get `/student/<username>`.
- Your card shows bio, reputation, proof counts, endorsements, and links. Only same-chapter members (or you) can view it unless you make it public.
- Follow builders and endorse skills from their cards.

## 6. Rules that protect you

- You can only see your own chapter's data (chapters opt in to what is public: directory cards, federation totals).
- Flag spam in forums/wiki; chapter admins moderate.
- Webhook events only ever attribute GitHub activity to the username you linked yourself.
- Everything has an honest empty state — if a page says "no data yet", that is the truth, not a bug.
